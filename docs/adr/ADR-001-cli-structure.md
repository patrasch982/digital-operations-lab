# ADR-001 – CLI statt einzelner Skripte

## Status

Accepted

## Kontext

Für wiederkehrende Verwaltungsaufgaben benötigen wir eine einfache Bedienoberfläche.

## Optionen

1. Viele einzelne Skripte (`status.sh`, `backup.sh`, `update.sh`)
2. Eine zentrale CLI (`lab`)

## Entscheidung

Wir verwenden eine zentrale CLI mit Unterbefehlen.

## Begründung

- Einheitliche Bedienung
- Einfach erweiterbar
- Klare Struktur
- Professioneller Aufbau
